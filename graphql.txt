Before testing GraphQL API, we must first find GraphQL endpoints. 
TESTING:- If you send query{__typename} to any GraphQL endpoint, it will include the string {"data": {"__typename": "query"}} somewhere in its response. 
This is known as a universal query, and is a useful tool in probing whether a URL corresponds to a GraphQL service.

GraphQL endpoints:- /graphql
                    /api
                    /api/graphql
                    /graphql/api
                    /graphql/graphql

 If these common endpoints don't return a GraphQL response, you could also try appending /v1 to the path.
